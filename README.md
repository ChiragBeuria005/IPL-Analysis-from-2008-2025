# 🏏 IPL Analytics Pro Dashboard

An advanced **IPL Data Analytics & Prediction Dashboard** built using **Streamlit, Machine Learning, and Data Visualization**.

---

## 🚀 Features

- 📊 Interactive Dashboard (Streamlit UI)
- 🔥 Top 15 Batsmen & Bowlers
- 🥧 Team-wise Run Distribution (Pie Chart)
- 🧡 Orange Cap Prediction (2026)
- 💜 Purple Cap Prediction (2026)
- 🏆 IPL 2026 Winner Prediction
- 📈 Machine Learning-based Predictions
- 📁 Smart Data Loading:
  - Kaggle Dataset
  - Local CSV
  - ZIP File Support

---

## 🧠 Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
